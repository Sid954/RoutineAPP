# My Routine v1.5.9 Release Notes

Fixes from your feedback on 1.5.8.

- **No more jumping when you switch days:** the schedule and the week strip change in place. Only the day you pick slides wider.
- **Nothing hidden under the menu bar:** the bottom of Apps, Notices, the post form, Faculty and Rooms is fully visible, including the Publish button.
- **One post form:** Simple mode is gone; the full form is back as the only mode. Tapping a class to post a test, cancellation, reschedule, online class or task still fills it in for you.
- **Home background** no longer stays visible on other pages after using the back button.
