# My Routine v1.5.6 Release Notes

Installs on top of v1.5.1 and later. No reinstall needed. This is the last update you download in the browser.

### Updates now install inside the app
- **No more browser downloads:** when a new version is out, a sheet shows what's new with **Update now**. The app downloads it with a progress bar, checks it isn't corrupted, and opens the Android installer.
- **Your choice:** Update now, Later, or Skip this version. Settings → Check for updates always shows the latest.
- **One-time permission:** the first time, Android asks you to allow installs from this app. Turn it on once and the update continues on its own.
- **Keep using the app** while it downloads. Hide the sheet and it comes back when the update is ready.
- **What's new:** after an update, the app shows what changed, once.
- Your routine, name, theme and notices stay as they are.
