# 🚀 My Routine v1.5.0 Release Notes

### 🎨 App Appearance & Theme Engine
- **8 Color Palettes**: Added Pitch Black (True AMOLED), Midnight Navy, Cyberpunk Neon, Emerald Forest, Sunset Glow, Oceanic Teal, Nordic Slate, and Crisp Light.
- **4 Design Styles**: Integrated Glassmorphic Cyber, Neumorphic 3D Soft, Cyberpunk HUD, and Bento Grid.
- **Unified Settings**: Integrated theme and palette customizers directly into the ⚙️ Edit Schedule modal with segmented style tabs and 4-column palette cards.
- **Android Status Bar Sync**: Auto-syncs Android status bar color with active theme and AMOLED mode.

### 📱 Main Dashboard Overhaul
- **Clean Luxury Canvas**: Replaced legacy animated RGB rainbow border with refined luxury glass borders and backdrop blur.
- **Modern Digital Clock**: Polished high-contrast typography with compact glowing `AM/PM` pill.
- **Compact Live Status Hub**:
  - Replaced oversized empty "Free Time" box with a compact status pill (`Free Time 🌴`).
  - Active classes feature live pulse ring, faculty badge, and glowing progress bar.
  - Next class card displays room number and live countdown ETA (`in 8h 12m`).
- **Timeline Schedule Cards**: Structured time column, prominent course titles, faculty chips, and class type tags.
- **Sleek Action Button**: Upgraded "View Full Routine" into a glass action bar with dynamic slide animation.

### 📢 Announcements Hub Redesign
- **Luxury Newsfeed Cards**: Removed dashed borders and replaced with solid, accent-bordered topic blocks.
- **Class Test & Exam Syllabus**: Displays exam name and syllabus topics in clean amber cards.
- **Online Class Launcher**: Direct `🚀 Join Online Class` link with virtual class timing.
- **Segmented Filter Tabs**: Smooth horizontal scrolling filter pills (`All`, `General`, `Cancelled`, `Holiday`, `Online`, `Exams`).
- **Auto-Adjusting Height**: Cards dynamically scale to fit all announcements without clipping.

### 🔔 Smart Notification Settings
- **Pill-Style Dropdowns**: Replaced oversized select boxes with compact pill selectors and custom chevron arrows.
- **Clean Text Alignment**: Fixed multiline text wrapping on setting labels.
- **Grouped Settings Cards**: Beautiful themed icon avatars and iOS-style animated spring switches.
- **Instant Auto-Save**: All notification preference toggles save immediately on change.

### 🏢 Campus Rooms & Faculty Directory
- **130 Faculty Members**: Direct directory with cabin numbers, email, phone, and weekly schedule lookups.
- **Vacant Classroom Finder**: Live vacancy tracker across all 33 campus rooms.

---

### 📦 Installation
- **Web App / PWA**: Available directly in browser with offline support.
- **Android APK**: Download `app-release.apk` and install on any Android device (Android 7.0+).
